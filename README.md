# Домашнее задание к работе 2

## Условие задачи

Мальчик может бегать в три раза быстрее, чем ходить. Скорость его ходьбы равна 4 км/час. Он принял участие в марафонском забеге, но сошел с дистанции, пробежав только x км. Сколько времени он затратил на преодоление этого расстояния?

---

## 1. Алгоритм и блок-схема

### Алгоритм

1. **Начало**
2. **Объявить константы и коэффициенты**:
   * `WALK_SPEED = 4.0` (км/ч) — скорость ходьбы.
   * `SPEED_RATIO = 3.0` — коэффициент увеличения скорости при беге.
3. **Задать исходные данные**:
   * `x` — расстояние, которое пробежал мальчик (км).
4. **Вычислить скорость бега**:
   * `run_speed = WALK_SPEED * SPEED_RATIO`
5. **Вычислить время в часах и минутах**:
   * `time_hours = x / run_speed`
   * `time_minutes = time_hours * 60.0`
6. **Вывести результаты расчетов** с подстановкой всех условий и значений в текст.
7. **Конец**
